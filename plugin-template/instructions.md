# Guia de exemplo

Este plugin adiciona orientação para respostas curtas e inclui um guia de referência pesquisável.

## Capacidades disponíveis

- `search_plugin_guide`: pesquisa os arquivos de texto incluídos no ZIP.
- `save_plugin_note`: salva uma nota no armazenamento local do navegador.

As ferramentas são declarações de dados. O núcleo aceita somente ações conhecidas e nunca executa JavaScript recebido no arquivo ZIP.
