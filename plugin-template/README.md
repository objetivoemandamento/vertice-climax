# Como criar o ZIP de exemplo

1. Mantenha `manifest.json` e `instructions.md` juntos na raiz de uma pasta.
2. Comprima os dois arquivos em um ZIP.
3. No Vértice, use **Instalar ZIP** e selecione o arquivo.

O ZIP pode conter arquivos de referência Markdown, texto, JSON ou YAML. Arquivos de programa não são executados. Veja [PLUGIN_FORMAT.md](../PLUGIN_FORMAT.md) para limites, ações e formato do manifesto.
